# Deband (устранение бэндинга)

## Что это
- **Deband** — фильтр постобработки в видеоредакторах/FFmpeg для удаления цветовых полос (banding) на градиентах.
- Замена соседних пикселей усреднённым значением снижает постеризацию.

## Где встречается
- Видео и изображения с плавными градиентами (небо, свет, стенки).
- После апскейла/ретуши, когда битность понижена.

## Реализация в FFmpeg
- Фильтр `deband` удаляет полосы, сравнивая текущий пиксель с четырьмя соседними.
- Ключевые опции:
  - `1thr`–`4thr` — пороги обнаружения (0.00003–0.5; по умолчанию 0.02).
  - `range` / `r` — радиус поиска в пикселях (по умолчанию 16).
  - `direction` / `d` — направление выборки (может быть фиксированным или случайным).
  - `blur` / `b` — усреднение соседних пикселей (включено по умолчанию).
  - `coupling` / `c` — синхронная обработка всех каналов.
- Пример: `ffmpeg -i input.mp4 -vf "deband=1thr=0.02:range=16" output.mp4`.

## Как применяют
- В графическом ПО (например, StarLight, Resolve) или через CLI.
- Подходит для финального грейда, токсинга телепрограммы, подготовки роликов под заказ.
