# 6 движений камеры (гайд One Minute Film School)

## Ссылка
- [YouTube Shorts](https://www.youtube.com/shorts/qO9U5pLnm5Y)

## Ключевые приёмы (по таймкодам)
- **0:00:12 — Dolly.** Физическое смещение камеры вперёд/назад относительно объекта (не zoom). Оборудование: дольли, слайдер.
- **0:15:21 — Boom.** Вертикальный подъём/опускание камеры. Оборудование: jib, кран.
- **0:23:27 — Truck.** Горизонтальное перемещение камеры влево/вправо. Оборудование: слайдер, дольли.
- **0:29:36 — Pan.** Поворот камеры на штативе по горизонтали (камера остаётся на месте).
- **0:38:42 — Tilt.** Поворот камеры на штативе по вертикали (смотрит вверх/вниз).
- **0:45:52 — Roll.** Физическое вращение камеры вокруг оптической оси (часто на гимбале).

## Применение для курса
- Базовый модуль по движению камеры: короткое объяснение + практические демонстрации.
- Рекомендация изучающим: комбинировать два движения для более динамичных кадров (совет из ролика).
- Включить в чек-лист подготовки съёмки: доступное оборудование для каждого движения.
