# Colleague skill для persona

## Источник

- Репозиторий: https://github.com/titanwings/colleague-skill
- Контекст: скилл для Claude / LLM, который помогает собирать и оформлять персону.

## Executive summary

Идея: использовать `colleague-skill` как основу для создания **persona-инструкций** из большого корпуса текстов. По описанию, сильная сторона подхода — не только сами тексты, а комбинация:

- **prompt engineering**
- **skill templates**
- **corpus synthesis**
- **layered persona files**

Это можно применять не только в HR/оценке, но и «во благо» — для моделирования **стиля, мировоззрения, способа мышления и принятия решений**.

## Практическая ценность

Судя по описанию, в систему можно скормить большой корпус материалов:

- труды философа
- тексты писателя
- работы учёного
- заметки / переписку / статьи конкретного автора

И затем превратить это в **рабочую инструкцию для persona**, которую LLM сможет использовать как слой поведения и выбора решений.

## Важная мысль

Чтобы такая persona работала лучше, одной инструкции может быть мало.

Имеет смысл связать её с:

- **полноценной RAG-системой**
- **NotebookLM**

Тогда можно не только хранить итоговую persona-инструкцию, но и подтягивать исходные материалы по запросу — то есть давать модели понимать, **что именно и откуда «вспоминать»**.

## Возможный пайплайн

1. Собрать корпус текстов автора / мыслителя / своей переписки.
2. Прогнать через `colleague-skill` или аналогичный шаблон persona synthesis.
3. Разделить результат на слои:
   - core persona
   - style / tone
   - decision heuristics
   - worldview / values
   - reference examples
4. Подключить RAG / NotebookLM для retrieval по исходным материалам.
5. Использовать persona не как жёсткую маску, а как управляемый слой поверх основной модели.
